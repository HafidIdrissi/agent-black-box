# Agent Black Box v0.1.0

Understand recorded coding-agent failures locally, without uploading session logs.

## Try it

Requires Node.js 22+. No install, build, account, or API key is needed.

```sh
git clone --branch v0.1.0 https://github.com/HafidIdrissi/agent-black-box.git
cd agent-black-box
npm start
```

Open http://127.0.0.1:8787/web/ and choose **Explore a failed run**, or import `examples/permission-loop.jsonl`.

## Included

- Claude Code JSONL and normalized v1 JSON imports.
- Correlated tool calls and results, searchable timeline, tool and error filters.
- Repeated tool/argument signals and best-effort secret masking.
- JSON exports, standalone script-free HTML reports, and a command-line analyzer.
- English and French documentation, 120 scoped issues, and [eight launch starter tasks](https://github.com/HafidIdrissi/agent-black-box/blob/main/docs/first-contribution.md#eight-places-to-start).

## Validation

The release workflow requires the six-platform CI matrix to succeed (Node 22 and 24 on Linux, Windows, and macOS). Its Chromium walkthrough checks the real import, counters, search, filters, HTML and JSON downloads, and reset behavior.

## Known limits

This is an early MVP. It does not capture live sessions, run agents, replay commands, compare sessions, calculate model costs, or support every agent format. Import limits are 10 MiB and 20,000 events. Repetition is an investigation signal. Masking is best effort: review reports before sharing them.

If you try it, a reproducible onboarding problem or small synthetic compatibility fixture is especially useful. Questions in French are welcome.
